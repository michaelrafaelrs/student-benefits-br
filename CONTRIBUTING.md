# Como contribuir

Contribuições são bem-vindas por meio de issues e pull requests.

1. Verifique se o programa já consta em `data/benefits/`.
2. Use um identificador estável, em minúsculas e com hífens.
3. Cite páginas **oficiais** de oferta e termos de elegibilidade.
4. Registre separadamente nível de ensino, idade, país, duração, restrições e data de conferência.
5. Não presuma elegibilidade no Brasil por existir uma página internacional.
6. Não registre percentual de desconto sem preço-base comparável.
7. Não inclua dados pessoais, credenciais ou documentos estudantis.

## Estados de verificação

- `confirmed_official`: a existência do programa foi verificada em fonte oficial.
- `pending`: informação aguardando comprovação.
- `expired`: oferta encerrada.
- `discontinued`: programa descontinuado.

`brazil_eligibility_confirmed` é um campo independente: confirmar a existência da oferta não confirma elegibilidade brasileira.

## Pull request

Descreva a alteração, os links oficiais consultados e a data de verificação. Mudanças em termos de elegibilidade devem citar a evidência relevante.
